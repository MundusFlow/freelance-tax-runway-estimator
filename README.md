# Freelance Tax & Runway Estimator

A free, no-signup web tool for freelancers to get instant estimates on two common money questions:

- **Tax Set-Aside** — how much to set aside for taxes this quarter, based on income and business expenses
- **Runway** — how many months current savings would cover personal expenses with no income

🔗 **Live site:** https://mundusflow.github.io/freelance-tax-runway-estimator/

## How it works

Everything runs client-side — plain HTML, CSS, and JavaScript, no backend, no data storage. Nothing typed into the calculators is sent or saved anywhere.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `style.css` | Styling |
| `script.js` | Calculator logic |

## Running locally

No build step needed — just open `index.html` directly in a browser.

## Related product

This tool links to **The Freelance CFO**, a paid Excel/Google Sheets workbook that tracks income, expenses, quarterly taxes, and runway automatically from real transaction data throughout the year.

## Disclaimer

These calculators provide estimates for planning purposes only and are not tax or financial advice. Consult a licensed professional for your specific situation.
